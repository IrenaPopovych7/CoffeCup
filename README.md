# Моя чашка ☕

Мобільний щоденник споживання кофеїну українською.

## Використання

Відкрийте сайт на телефоні, оберіть напій або додайте власний. Застосунок підраховує приблизну кількість кофеїну за вибраний день, показує залишок до орієнтира 200 мг та зберігає історію у localStorage браузера.

## GitHub Pages

Repository **Settings → Pages → Build and deployment → Deploy from a branch → main → / (root) → Save**.

Після першого розгортання: https://irenapopovych7.github.io/CoffeCup/

## Конфіденційність

Немає сервера, акаунтів чи аналітики. Записи не передаються в інтернет, а зберігаються лише в браузері пристрою. Очищення даних браузера видалить історію.

## Медичне застереження

200 мг — загальний орієнтир під час планування вагітності, не персоналізоване медичне призначення. Реальний вміст кофеїну залежить від приготування й розміру порції. Слід дотримуватися порад клініки ЕКЗ.
